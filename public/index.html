Documentation Workflow MCP

This is a self-hosted documentation MCP server.

Your AI (Claude, Copilot, Cursor and others) connects here to write, check, publish, promote and roll back documentation in your own Firebase.

Connect your AI

Use this server's address followed by /mcp, with the server's bearer token:

URL:    https://<this-server>/mcp
Header: Authorization: Bearer <MCP_BEARER_TOKEN>

Ask the person who runs this server for the token. Never share it in chat or commit it to a repository.

Check it is running

/health shows the server version, how many projects it has and whether encryption is set up.

Set it up yourself

The README in the source repository explains installation, projects, reader access, encryption, Orbit and moving projects to or from the hosted service.
