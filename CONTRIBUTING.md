# Contributing

Thank you for helping. Bug reports, documentation fixes and pull requests are all welcome.

## Before you start

- For anything bigger than a small fix, open an issue first so we can agree on the approach.
- Never include real customer data, Firebase keys, tokens or `projects.json` in issues, commits or tests. Use made-up names such as "Acme".

## Making a change

1. Fork the repository and create a branch.
2. Install and test:

   ```bash
   npm ci
   ```

   ```bash
   npm test
   ```

3. Keep the change focused, add or update tests, and describe in the pull request what changed and why.

## Contributor License Agreement

Before we can merge your first pull request, you sign our Contributor License Agreement (a bot asks you on the pull request). It confirms that you have the right to contribute the code and allows the maintainers to offer the project under both the AGPL-3.0 and a commercial license. You keep the copyright to your contribution.

## Code of conduct

Be respectful and constructive. Harassment of any kind is not tolerated.
